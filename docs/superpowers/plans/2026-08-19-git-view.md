# Git Source-Control View + Cwd Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Part 2 of the approved spec (`docs/superpowers/specs/2026-08-19-tauri-port-and-git-view-design.md`): a VS Code-style interactive source-control sidebar (status, stage/unstage/discard, commit, push/pull/fetch, commit graph) that follows the focused terminal's repo — plus the user-requested cwd features: a clickable current-directory path in each pane toolbar and splits that start in the source pane's live cwd.

**Architecture:** A Rust `git.rs` module shells out to the `git` CLI under strict process hygiene (literal pathspecs, timeouts with process-group kill, output caps, per-repo serialization) behind an interning repo registry; porcelain-v2 and log parsing plus the graph lane layout are pure Rust functions with fixture tests. The renderer gets a `git-store.ts` (existing hand-rolled store pattern) with focus-follow + generation-guarded refresh, and a `components/git/` sidebar. Cwd features ride on the port's `pty_cwd`.

**Tech Stack:** existing only — Rust std (direct `extern "C"` for `setpgid`/`kill`, same pattern as `proc_cwd`), serde/serde_json, git CLI; React 18 + existing store pattern; no new dependencies (crates or npm).

## Global Constraints

- Every git invocation: `git -C <repo>` + env `GIT_TERMINAL_PROMPT=0`, `GIT_OPTIONAL_LOCKS=0`, `GIT_LITERAL_PATHSPECS=1`, `LC_ALL=C`; stdin null; stdout cap 1 MB / stderr cap 64 KB — **over-cap kills the process group and returns an explicit "output too large" error; truncated output is never parsed**; timeout 10s (local) / 120s (network: push/pull/fetch) with process-group kill.
- `repo_id` is opaque; canonical roots live only in the backend registry, **interned** (same root → same id). One action at a time per repo; status refreshes: at most one in flight per repo, skipped while an action holds the repo.
- Renames expand to both paths; copies act on destination only (stage/unstage/discard alike); unmerged entries excluded from plain discard (stage-as-resolved only); submodule discard rejected backend-side; unborn-HEAD unstage uses `git rm --cached -r -f --`; discard revalidates paths against a fresh status backend-side.
- Non-UTF-8 paths: displayed lossily, `actionable: false`, all actions rejected (revalidation cannot match them).
- Sidebar closed → zero git activity. Poll 3s while open, backing off ×2 up to 15s when status takes >500ms.
- All commits on branch `feat/git-view`; commit messages end with the standard Co-Authored-By/Claude-Session trailer used on this repo.

```rust
use std::io::Read;
use std::path::Path;
use std::process::{Command, Stdio};
use std::sync::mpsc;
use std::time::{Duration, Instant};

pub struct GitOutput {
    pub stdout: Vec<u8>,
    pub stderr: String,
}

const STDOUT_CAP: usize = 1024 * 1024;
const STDERR_CAP: usize = 64 * 1024;
const LOCAL_TIMEOUT: Duration = Duration::from_secs(10);
const NETWORK_TIMEOUT: Duration = Duration::from_secs(120);

extern "C" {
    fn setpgid(pid: i32, pgid: i32) -> i32;
    fn kill(pid: i32, sig: i32) -> i32;
}
const SIGKILL: i32 = 9;

fn kill_group(pid: u32) {
    unsafe {
        let _ = kill(-(pid as i32), SIGKILL);
    }
}

pub fn run_git(repo: Option<&Path>, args: &[&str], network: bool) -> Result<GitOutput, String> {
    let mut full: Vec<&str> = Vec::new();
    let repo_str;
    if let Some(r) = repo {
        repo_str = r.to_string_lossy().into_owned();
        full.push("-C");
        full.push(&repo_str);
    }
    full.extend_from_slice(args);
    let timeout = if network { NETWORK_TIMEOUT } else { LOCAL_TIMEOUT };
    run_command_with_timeout_and_cap_env("git", &full, timeout, STDOUT_CAP)
}

// (internal; the _env variant sets the git hygiene env, the plain variants
// exist for the timeout/cap unit tests with arbitrary binaries)
pub(crate) fn run_command_with_timeout_and_cap_env(
    cmd: &str, args: &[&str], timeout: Duration, cap: usize,
) -> Result<GitOutput, String> {
    let mut command = Command::new(cmd);
    command
        .args(args)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .env("GIT_TERMINAL_PROMPT", "0")
        .env("GIT_OPTIONAL_LOCKS", "0")
        .env("GIT_LITERAL_PATHSPECS", "1")
        .env("LC_ALL", "C");
    #[cfg(unix)]
    unsafe {
        use std::os::unix::process::CommandExt;
        command.pre_exec(|| {
            setpgid(0, 0);
            Ok(())
        });
    }
    let mut child = command.spawn().map_err(|e| e.to_string())?;
    let pid = child.id();

    // Reader threads report progress so the cap can trip mid-stream.
    let (tx, rx) = mpsc::channel::<(bool, Vec<u8>)>(); // (is_stdout, chunk)
    let mut stdout_pipe = child.stdout.take().unwrap();
    let mut stderr_pipe = child.stderr.take().unwrap();
    let tx2 = tx.clone();
    let so = std::thread::spawn(move || {
        let mut buf = [0u8; 32 * 1024];
        while let Ok(n) = stdout_pipe.read(&mut buf) {
            if n == 0 { break; }
            if tx.send((true, buf[..n].to_vec())).is_err() { break; }
        }
    });
    let se = std::thread::spawn(move || {
        let mut buf = [0u8; 8 * 1024];
        while let Ok(n) = stderr_pipe.read(&mut buf) {
            if n == 0 { break; }
            if tx2.send((false, buf[..n].to_vec())).is_err() { break; }
        }
    });

    let deadline = Instant::now() + timeout;
    let mut stdout: Vec<u8> = Vec::new();
    let mut stderr_bytes: Vec<u8> = Vec::new();
    let mut failure: Option<String> = None;
    loop {
        // Drain pending chunks
        while let Ok((is_out, chunk)) = rx.try_recv() {
            let (buf, capn) = if is_out { (&mut stdout, cap) } else { (&mut stderr_bytes, STDERR_CAP) };
            buf.extend_from_slice(&chunk);
            if buf.len() > capn {
                failure = Some("output too large".to_string());
            }
        }
        if failure.is_some() {
            kill_group(pid);
            let _ = child.kill();
            let _ = child.wait();
            break;
        }
        match child.try_wait() {
            Ok(Some(status)) => {
                let _ = so.join();
                let _ = se.join();
                while let Ok((is_out, chunk)) = rx.try_recv() {
                    if is_out { stdout.extend_from_slice(&chunk); } else { stderr_bytes.extend_from_slice(&chunk); }
                }
                let stderr = String::from_utf8_lossy(&stderr_bytes).into_owned();
                if stdout.len() > cap || stderr_bytes.len() > STDERR_CAP {
                    return Err("output too large".to_string());
                }
                if status.success() {
                    return Ok(GitOutput { stdout, stderr });
                }
                let code = status.code().unwrap_or(-1);
                let head: String = stderr.chars().take(400).collect();
                return Err(format!("exit {code}: {head}"));
            }
            Ok(None) => {
                if Instant::now() >= deadline {
                    failure = Some(format!("timeout after {}s", timeout.as_secs()));
                    kill_group(pid);
                    let _ = child.kill();
                    let _ = child.wait();
                    break;
                }
                std::thread::sleep(Duration::from_millis(20));
            }
            Err(e) => {
                failure = Some(e.to_string());
                kill_group(pid);
                break;
            }
        }
    }
    let _ = so.join();
    let _ = se.join();
    Err(failure.unwrap_or_else(|| "unknown git failure".to_string()))
}
```

```rust
pub struct RepoEntry {
    pub root: std::path::PathBuf,
    pub action_lock: Arc<Mutex<()>>,
    pub status_inflight: Arc<std::sync::atomic::AtomicBool>,
}

#[derive(Default)]
pub struct GitState {
    // canonical root -> repo_id, and repo_id -> entry
    by_root: Mutex<HashMap<PathBuf, String>>,
    by_id: Mutex<HashMap<String, Arc<RepoEntry>>>,
    next_id: std::sync::atomic::AtomicU64,
}

impl GitState {
    pub fn resolve(&self, cwd: &str) -> Option<RepoInfo> {
        let out = process::run_git(Some(Path::new(cwd)), &["rev-parse", "--show-toplevel"], false).ok()?;
        let root_str = String::from_utf8_lossy(&out.stdout).trim().to_string();
        if root_str.is_empty() { return None; }
        let root = std::fs::canonicalize(&root_str).ok()?;
        let mut by_root = self.by_root.lock().unwrap();
        let id = by_root.entry(root.clone()).or_insert_with(|| {
            let id = format!("repo-{}", self.next_id.fetch_add(1, std::sync::atomic::Ordering::SeqCst));
            self.by_id.lock().unwrap().insert(id.clone(), Arc::new(RepoEntry {
                root: root.clone(),
                action_lock: Arc::new(Mutex::new(())),
                status_inflight: Arc::new(std::sync::atomic::AtomicBool::new(false)),
            }));
            id
        }).clone();
        let display_name = root.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_else(|| root_str.clone());
        Some(RepoInfo { repo_id: id, display_name, root: root.to_string_lossy().into_owned() })
    }

    pub fn entry(&self, repo_id: &str) -> Option<Arc<RepoEntry>> {
        self.by_id.lock().unwrap().get(repo_id).cloned()
    }
}
```

## Rev 2 — Codex review amendments (BINDING: these override the task text above)

Codex review returned 6 blocking + 12 should-fix findings. Corrections, all binding on the implementer:

**A. Task order changes (finding 18).** Backend graph work (old Task 4) moves AFTER actions + network: execute as T2 process/registry → T3 status → T4 actions (old T5) → T5 network (old T6) → T6 graph backend (old T4) → T7 store → T8 sidebar UI → T9 graph UI → T10 gate. Graph command is named **`git_graph`** (not `git_log`) per spec; initial limit 300, load-more +300, **hard cap 1000** (hide the button at cap).

**B. run_git loop redesign (finding 1).** The `try_recv`-drain + sleep loop cannot trip the cap under a fast producer and appends before checking. Correct shape: blocking `rx.recv_timeout(20ms)` loop —
- `Ok(chunk)`: **check `buf.len() + chunk.len() > cap` BEFORE appending**; over-cap → `kill_group(pid)`, `child.kill()`, set failure, break.
- `Err(Timeout)`: deadline passed → kill group + child, failure, break; else continue.
- `Err(Disconnected)` (both readers done): break with success-pending.
After the loop, **always**: `child.kill()` best-effort on failure paths, then bounded wait — poll `try_wait` until the deadline (a process can close pipes and keep running; never block on `wait()` unbounded), then join reader threads (pipes are closed by then). `pre_exec` ignores `setpgid` failure (returns Ok) and `kill_group` is best-effort alongside `child.kill()`. Timeout error string uses milliseconds under 1s: `"timeout after 300ms"` (adjust the test to expect that).

**C. Porcelain v2 exact tokenization (findings 2, 7, 8).** Use bounded `splitn` on spaces with exact counts; never unrestricted whitespace splitting (paths may contain spaces/tabs/newlines):
- type `1`: `splitn(9)` — `1 XY sub mH mI mW hH hI <path>`, path = token 9.
- type `2`: `splitn(10)` — `1..8 as above, Xscore, <path>`, path = token 10; **the next NUL record is `orig_path`**.
- type `u`: per git docs `u XY sub m1 m2 m3 mW h1 h2 h3 <path>` — implement with the doc's field list and **pin the arity empirically**: the integration fixture must include a real conflict and assert the parsed *pathname and both status chars* exactly (the review flagged arity ambiguity; the real-git fixture is the tiebreaker).
- The `z()` test helper must actually append the trailing NUL.
- Rename/copy entries are `actionable` only if **both** `path` and `orig_path` are valid UTF-8; add fixtures with invalid UTF-8 on each side, plus paths containing newlines, plus at least `UU`, `AA`, `DU` unmerged combos.

**D. Log parsing (finding 3).** Subject `%s` goes LAST in the format; parse each record with **bounded `splitn(6, '\x1f')`** so a subject containing `\x1f` survives. `%D` is kept as a **single display string** (`refs_display: String` replaces `refs: Vec<String>`); the UI may cosmetically split on `", "` for badges but no logic depends on ref parsing. Fixtures: multi-record input, subject containing `\x1f` and commas, refs string with commas.

**E. Lane layout precise algorithm (finding 4).** Per row (commit): (1) lane = leftmost lane expecting this hash, else first free (`None`) slot, else append. (2) Any OTHER lane also expecting this hash: emit fold edge `that_lane → lane` on THIS row and free it. (3) Continuation edges `j → j` on this row for every other occupied lane j. (4) Parents: first parent p0 — if some lane k already expects p0, emit `lane → k` on this row and free `lane` (this is what folds a feature branch into its base **on the feature commit's row**, as the merge test requires); else `active[lane] = p0`, edge `lane → lane`. Other parents pi — if lane k expects pi, edge `lane → k`; else claim first free slot (or append) k, set expectation, edge `lane → k`. (5) No parents: free the lane, no downward edge. Freed slots are reused; `lane_count` = max simultaneously-occupied. Drop the "collapse-shift" wording; the merge-test expectation (`f`'s fold edge on `f`'s row) is satisfied by rule 4.

**F. Action layer (findings 9, 10).** Discard's restore-source+clean-dest applies **only to type-2 entries whose worktree status is `R`**; a staged rename with an unrelated worktree modification is NOT a worktree rename (its worktree side discards as an ordinary path). Copy semantics dispatch on worktree `C`. **Bulk operations never use `-A`/bare `reset`/`.`** — they expand to the explicit list of actionable paths (non-actionable entries are skipped; if any were skipped, the returned report is accompanied by a warning string field `skipped: u32` on the response — UI shows a muted note). Unborn bulk unstage = `rm --cached -r -f -- <explicit paths>`; normal bulk unstage = `restore --staged -- <explicit paths>`. Additional required tests: rename unstage expands both paths; copy stage/unstage destination-only; staged-rename+worktree-mod discard treats sides independently; backend rejects an action naming a non-actionable path; submodule stage/unstage allowed (gitlink); bulk unstage both modes.

- Focus-follow subscribes ONLY while the sidebar is open; opening resolves the currently-focused terminal. Test: focus changes while closed produce **zero** bridge calls.
